# AutoPaper Privacy Policy

Effective date: August 15, 2026

AutoPaper is an offline Markdown reader and previewer. It does not collect, transmit, sell, or share personal information, browsing history, local file contents, analytics, or usage data.

## Data processed on your device

- When you open a local `.md` or `.markdown` file, AutoPaper reads that file in the browser solely to render the reading view. The content remains on your device.
- Text entered in the popup editor is stored in `chrome.storage.local` so the draft is available the next time you open the popup. This data remains in the current browser profile and is not transmitted to the developer or any third party.
- AutoPaper does not use cookies, remote analytics, advertising SDKs, accounts, or developer-operated servers.

## Permissions

- `storage` stores the popup editor draft locally.
- `file:///*` lets AutoPaper render local Markdown files after the user explicitly enables “Allow access to file URLs” in Chrome. AutoPaper ignores local files that do not end in `.md` or `.markdown`.

## Data deletion

Users can delete the saved editor draft with the Clear button, clear extension storage from Chrome, or uninstall AutoPaper. AutoPaper retains no server-side copy because it operates without a server.

## Changes and contact

Material changes to this policy will be reflected in the policy date and in the extension listing. Support contact and the public policy URL are maintained in the Chrome Web Store listing.
