# AGI Tools

面向个人智能工作流的轻量工具集合。

## 工具

### [AutoPaper — Local Markdown Reader](autopaper/)

Chrome / Edge Manifest V3 扩展。直接把本地 Markdown 文件排版为带目录的阅读页，也提供离线双栏编辑与实时预览。

- 无账号、广告、分析脚本或远程代码；
- Markdown 内容和草稿只在当前浏览器处理；
- 支持标题、列表、引用、代码块、表格、链接与图片；
- 包含中英文界面、测试、图标和 Chrome Web Store 素材。

安装方法见 [`autopaper/README.md`](autopaper/README.md)。
